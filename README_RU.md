# RU BG26 — русскоязычный D&D-компаньон

Стартовый проект для расширения `@RU_BG26_bot`: личное кнопочное меню + команды в группе.

## Что уже есть в этой стартовой версии

- Личное меню с кнопками: кубики, бестиарий, заклинания, предметы, инструменты мастера.
- Кубики с подробным разбором: каждый результат, сумма кубиков, бонус и итог.
- Короткие записи бросков: `/d20`, `/d20+5`; `/roll 5d8+3`. В личке также поддерживается `/5d8`.
- Кнопочный выбор типа кости, количества и бонуса.
- Связь личного кабинета с одной группой через `/link`; из лички результат можно отправить в группу.
- Ссылки на каталоги D&D.su 2014/2024 для бестиария, заклинаний и магических предметов.
- Небольшой локальный индекс имён монстров, ПО и XP для ориентировочных подсказок и генератора столкновений. Он **не заменяет полные статблоки**.
- Генератор лута с настройкой диапазона уровня и типа награды.
- Генератор столкновений с числом игроков, уровнем, сложностью и окружением. Оценка использует пороги XP 2014 и помечена как приблизительная; для 2024 есть ссылка на отдельный планировщик.
- Генератор NPC и случайных событий.
- Трекер инициативы в группе: `/init add`, `/init`, `/init next`, `/init hp`, `/init clear`.
- Журнал заметок кампании: `/note`, `/notes`.
- Необязательный ИИ-помощник через `/ask`, если владелец настроит API-ключ.
- SQLite-хранилище для связей с группами, заметок и инициативы.

## Чего пока нет

1. Полные карточки монстров, заклинаний и предметов внутри Telegram из D&D.su. В текущей версии бот открывает нужный каталог и показывает небольшой локальный индекс. Это сделано намеренно: не найден подтверждённый публичный API D&D.su, а автоматическое массовое копирование описаний без разрешения не закладывается. Если у тебя есть разрешённый API/экспорт/разрешение владельцев, подключим полноценный поиск.
2. Автоматическая синхронизация листов персонажей и их способностей.
3. Проверка боя с точным учётом всех способностей существ и правил смешанной редакции. Генератор столкновений сейчас даёт черновую подборку, которую должен проверить мастер.
4. Сеансы кнопочного меню хранятся в оперативной памяти и сбросятся при перезапуске; важные игровые данные остаются в SQLite.

## Установка на своём компьютере

Нужен Python 3.11+ (проект рассчитан на Python 3.12).

1. Сделай резервную копию старого кода, если он существует. **Не запускай две программы с одним токеном одновременно**: если старый процесс получает обновления через polling, сначала останови его или объедини код.
2. В `@BotFather` открой своего бота и получи токен локально. Не присылай его в переписку.
3. Скопируй `.env.example` в `.env` и задай `BOT_TOKEN`.
4. Узнай Telegram ID мастера, запусти тестовую версию и отправь боту `/myid`; впиши числовой ID в `MASTER_IDS` в `.env`. Перезапусти программу.
5. Установи зависимости и запусти:

   ```bash
   python -m venv .venv
   # Windows PowerShell:
   .venv\Scripts\Activate.ps1
   # macOS/Linux:
   source .venv/bin/activate
   pip install -r requirements.txt
   python main.py
   ```

6. Напиши боту `/start` в личке. В группе добавь бота и отправь `/link`. Каждый игрок должен открыть выданную ссылку и нажать Start — после этого личный бросок можно публиковать в группу.

Для постоянной работы перенеси проект на VPS/облачный хостинг и используй Dockerfile или аналогичный способ запуска. SQLite файл `data/bot.sqlite3` нужно сохранять между перезапусками и резервировать.

## Настройка бросков в группах

Команды `/d20` и `/roll 5d8+3` удобнее всего для групп. В Telegram команды ботов обычно начинаются с буквы, поэтому короткая запись `/5d8` может не распознаваться как команда в группе при стандартном Privacy Mode. Варианты:

- рекомендованный безопасный вариант: использовать `/roll 5d8+3` в группе;
- если принципиально нужна именно `/5d8`, открой `@BotFather` → `/setprivacy` → выбери бота → `Disable`, затем проверь получение сообщений в группе. При отключённой приватности Telegram сможет передавать боту обычные сообщения группы; приложение не сохраняет обычный текст, но технически процесс его получает. Делай это только если всех участников устраивает такая настройка.

## Команды

- `/start`, `/menu`, `/help`, `/myid`
- `/d20`, `/d20+5`, `/roll 5d8+3`
- `/monster гоблин`, `/spell огненный шар`, `/item плащ защиты`
- `/loot`, `/encounter`, `/npc`, `/event`
- `/init` — показать инициативу
- `/init add Гоблин 12 7` — добавить участника с инициативой 12 и 7 HP
- `/init next` — следующий ход
- `/init hp Гоблин -3` — снять 3 HP
- `/init clear` — очистить список боя
- `/note Советник видел странный герб` — сохранить заметку (мастер/администратор)
- `/notes` — последние заметки
- `/ask Как сделать бой интереснее?` — ИИ (нужен `OPENAI_API_KEY`)
- `/link` в группе — сгенерировать ссылку для привязки личного кабинета
